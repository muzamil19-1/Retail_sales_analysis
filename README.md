# Retail_sales_analysis- Power BI Project

## 📌 Project Overview

This project presents an interactive Sales Performance Dashboard built using Microsoft Power BI.
The dashboard helps analyze sales trends, customer behavior, product performance, and regional insights for better business decision-making.

---

## 🎯 Project Objectives

* Analyze overall sales performance
* Identify top-performing products and categories
* Understand customer purchasing behavior
* Compare regional sales performance
* Track monthly sales trends

---

## 🗂 Dataset Information

The dataset contains 3 tables:

**1️⃣ Customers Table**

* Customer ID
* Customer Name
* City
* Region
* Age

**2️⃣ Products Table**

* Product ID
* Product Name
* Category
* Sub-Category
* Price

**3️⃣ Orders Table**

* Order ID
* Order Date
* Customer ID
* Product ID
* Quantity
* Revenue

---

## 🛠 Tools & Technologies Used

* Microsoft Power BI
* Power Query (Data Cleaning & Transformation)
* DAX (Data Analysis Expressions)
* Data Modeling (Star Schema)

---

## 🔄 Data Preparation Steps

* Removed duplicate values
* Cleaned missing and incorrect data
* Changed data types
* Created relationships between tables
* Built calculated columns and measures using DAX

---

## 📈 Dashboard Features

* KPI Cards (Total Revenue, Orders,Average Sales)
* Sales by Category Analysis
* Regional Sales Performance
* Monthly Sales Trend
* Top 5 Products by Revenue
* Interactive Filters (Year, Region, Category)

---

## 🔍 Key Insights

1. Grocery category generated the highest revenue.
2. South region contributed the largest share of sales.
3. Sales show a consistent Downward monthly trend.
4. Top products contribute most of the overall revenue.
5. Jaipur city generated the highest revenue.
